# xrwvm-fullstack_developer_capstone

## Project Name: Best Cars Dealership

## Description
A full stack web application for a national car dealership that allows customers to browse dealers by state, read and submit reviews, and analyze review sentiments using AI.

## Repository Name
xrwvm-fullstack_developer_capstone

## Tech Stack
- Frontend: React.js
- Backend: Django (Python)
- Database: MongoDB
- Sentiment Analysis: IBM Watson NLU
- Deployment: IBM Cloud Code Engine + Kubernetes

## Features
- User registration and login
- Browse car dealerships by state
- View and submit dealer reviews
- Sentiment analysis on reviews (positive/negative/neutral)
- CI/CD with GitHub Actions
